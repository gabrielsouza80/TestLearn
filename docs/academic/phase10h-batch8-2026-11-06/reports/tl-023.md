## Solução independente / Independent pre-key solution

Learning while designing, executing and evaluating, in a timeboxed session guided by a charter, characterizes session-based exploratory testing. Unadapted predefined replay lacks the described adaptive design; error guessing can contribute experience-based ideas without defining this full process; a checklist alone does not characterize concurrent learning/design/execution. The scenario describes this structured variant, not a universal requirement that all exploratory testing must use timeboxes/charters.
